# Динамическая система колонок в ProductList

## 🎯 Цель
Заменить статичные колонки на динамические, которые автоматически создаются для каждой стадии с назначенными сотрудниками.

## ✅ Что изменилось

### ❌ Убрано:
- Статичная колонка "Стадии" 
- Статичные колонки "Дизайнеры", "Печатники", "Гравировщики", "Работники цеха"

### ✅ Добавлено:
- **Динамические колонки** - автоматически создаются для каждой стадии с ролями
- **Автоматическое обновление** - новые стадии автоматически добавляют новые колонки
- **Гибкость** - система работает с любым количеством стадий и ролей

## 🔧 Как это работает

### 1. Базовые колонки
```typescript
const baseColumns: Column[] = [
  { key: 'id', label: 'ID', sortable: true },
  { key: 'name', label: 'Название', sortable: true },
  { key: 'created_at', label: 'Создано', sortable: true },
]
```

### 2. Динамические колонки
```typescript
const dynamicColumns = computed<Column[]>(() => {
  const columns = [...baseColumns]
  
  // Анализируем все продукты и их стадии
  const stageAssignments = new Map()
  
  pagination.value?.data.forEach(product => {
    if (product.available_stages) {
      product.available_stages.forEach(stage => {
        if (stage.roles && stage.roles.length > 0) {
          stage.roles.forEach(role => {
            const key = `${stage.id}_${role.name}`
            if (!stageAssignments.has(key)) {
              stageAssignments.set(key, {
                stageId: stage.id,
                stageName: stage.display_name,
                roleType: role.name,
                roleDisplayName: role.display_name,
                color: stage.color
              })
            }
          })
        }
      })
    }
  })
  
  // Создаем колонки для каждой стадии с назначениями
  stageAssignments.forEach((assignment, key) => {
    columns.push({
      key: `stage_${key}`,
      label: `${assignment.stageName} (${getRoleDisplayName(assignment.roleType)})`,
      sortable: false,
      type: 'stage_assignments',
      stageId: assignment.stageId,
      roleType: assignment.roleType,
      color: assignment.color
    })
  })
  
  return columns
})
```

### 3. Отображение назначений
```typescript
function getStageAssignments(product: Product, stageId: number, roleType: string) {
  // Пока используем старые поля для обратной совместимости
  const roleMap = {
    designer: product.designers || [],
    print_operator: product.print_operators || [],
    engraving_operator: product.engraving_operators || [],
    workshop_worker: product.workshop_workers || [],
  }
  
  return roleMap[roleType] || []
}
```

## 🚀 Преимущества

### ✅ Автоматичность
- Новые стадии автоматически создают новые колонки
- Не нужно изменять код при добавлении стадий

### ✅ Гибкость  
- Работает с любым количеством стадий
- Поддерживает любые роли
- Адаптируется к изменениям в системе

### ✅ Читаемость
- Каждая колонка четко показывает стадию и роль
- Легко понять, кто назначен на какую стадию

### ✅ Масштабируемость
- Система готова к росту количества стадий
- Не требует переписывания кода
