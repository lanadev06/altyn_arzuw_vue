# Отчет об исправлении проблем с цветами стадий

## Проблемы, которые были исправлены

### 1. Проблема с Tailwind CSS динамическими классами

**Проблема**: Использование `bg-[${color}]` не работает корректно, так как Tailwind не может сгенерировать классы для динамических цветов.

**Решение**:

- Заменил динамические классы на inline стили для кастомных цветов
- Добавил fallback на предопределенные Tailwind классы для стандартных стадий
- Создал функцию `getStageColorStyles()` для получения inline стилей

### 2. Несоответствие цветов в разных компонентах

**Проблема**: В разных местах использовались разные подходы к цветам стадий.

**Решение**:

- Унифицировал подход к цветам через централизованную утилиту `stageColors.ts`
- Добавил функции для работы с контрастом и светлыми версиями цветов
- Обновил все компоненты для использования единого подхода

### 3. Проблемы с контрастом текста

**Проблема**: Функции для работы с цветами работали некорректно.

**Решение**:

- Улучшил функцию `getContrastColor()` для правильного определения цвета текста
- Добавил функцию `getLightColor()` для создания светлых версий цветов
- Экспортировал эти функции из утилиты для использования в компонентах

## Результат

Теперь система цветов стадий работает корректно:

1. **Динамические цвета**: Кастомные цвета из API применяются через inline стили
2. **Fallback цвета**: Если кастомный цвет не найден, используются предопределенные Tailwind классы
3. **Контраст**: Текст автоматически подбирается для лучшей читаемости
4. **Единообразие**: Все компоненты используют единый подход к цветам

## Дополнительные исправления

### Исправление серых цветов в "Заказы по сотрудникам"

**Проблема**: В разделе "Заказы по сотрудникам" стадии отображались серым цветом, потому что использовалась функция `statusBadgeClass()` вместо `stageColor()`.

**Решение**:

- Заменил `statusBadgeClass()` на `stageColor()` и `stageColorStyle()`
- Обновил функцию `stageColor()` для возврата правильных Tailwind классов с цветами текста
- Теперь стадии отображаются с правильными цветами: синий для "Дизайн", оранжевый для "Гравировка", зеленый для "Завершён" и т.д.
