## 🚀 КАК ИСПОЛЬЗОВАТЬ

### **1. Управление стадиями:**

1. Перейдите в меню "Стадии" (только для админов)
2. Нажмите "Добавить стадию"
3. Заполните форму:
   - **Название (slug):** `design`
   - **Отображаемое название:** `Дизайн`
   - **Описание:** `Создание дизайна`
   - **Порядок:** `2`
   - **Цвет:** Выберите цвет
   - **Тип:** Начальная/Финальная/Обычная
4. Сохраните

### **2. Управление ролями:**

1. Перейдите в меню "Роли" (только для админов)
2. Нажмите "Добавить роль"
3. Заполните форму:
   - **Название (slug):** `designer`
   - **Отображаемое название:** `Дизайнер`
   - **Описание:** `Создание дизайнов`
4. Сохраните
5. Нажмите на количество пользователей для назначения

### **3. Использование в продуктах:**

1. При создании продукта выберите нужные стадии
2. Установите стадию по умолчанию
3. Сохраните продукт
