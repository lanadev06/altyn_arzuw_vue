# Инструкция по удалению ролей

## ✅ Исправления

**Исправлена ошибка:** `Call to undefined method App\Models\User::orderAssignments()`

- Проблема была в том, что в `RoleController` использовалось неправильное название отношения
- Исправлено: `orderAssignments` → `assignments`
- Теперь удаление ролей работает корректно

## Как удалить роль

### 1. Через веб-интерфейс (рекомендуется)

1. **Войдите в систему как администратор**

   - Убедитесь, что у вас есть роль 'admin'
   - Проверьте, что вы залогинены

2. **Перейдите в раздел "Роли"**

   - В меню найдите "Роли" или "Управление ролями"
   - Откроется список всех ролей

3. **Найдите роль для удаления**

   - Просмотрите список ролей
   - Обратите внимание на количество пользователей в каждой роли
   - **Не удаляйте системные роли**: admin, manager, designer, print_operator, workshop_worker, engraving_operator

4. **Откройте роль для редактирования**

   - Нажмите на роль в списке
   - Откроется модальное окно редактирования

5. **Нажмите кнопку "Удалить"**
   - Кнопка удаления показывается только администраторам
   - Появится подтверждение удаления
   - Подтвердите удаление

### 2. Проверка перед удалением

**Роль можно удалить, если:**

- ✅ У неё нет активных назначений в заказах
- ✅ Она не является системной ролью
- ✅ У вас есть права администратора

**Роль НЕЛЬЗЯ удалить, если:**

- ❌ Она используется в активных назначениях
- ❌ Это системная роль (admin, manager, designer, etc.)
- ❌ У вас нет прав администратора

### 3. Отладка проблем

#### Если кнопка удаления не появляется:

1. Проверьте, что вы залогинены как администратор
2. Откройте DevTools (F12) → Console
3. Выполните:

```javascript
// Проверить токен
console.log('Token:', localStorage.getItem('auth_token'))

// Проверить пользователя
const user = JSON.parse(localStorage.getItem('user') || '{}')
console.log('User:', user)
console.log('Roles:', user.roles)
```

#### Если удаление не работает:

1. Откройте DevTools (F12) → Console
2. Попробуйте удалить роль
3. Проверьте логи в консоли на ошибки
4. Используйте тестовый файл `test-role-deletion.html`

### 4. Тестовый файл

Откройте файл `test-role-deletion.html` в браузере для тестирования:

1. **Проверьте токен** - должен быть найден
2. **Проверьте права** - должен быть админ
3. **Загрузите роли** - увидите список всех ролей
4. **Попробуйте удалить роль** - введите ID роли и нажмите "Удалить"

### 6. Логика удаления

При удалении роли происходит:

1. Проверка прав доступа (только админ)
2. Проверка токена авторизации
3. Проверка активных назначений через отношение `assignments`
4. Удаление связей роли с пользователями
5. Удаление связей роли со стадиями
6. Удаление самой роли (физическое удаление)

### 7. Восстановление

Если роль была удалена по ошибке:

1. Роли удаляются физически (не используется `SoftDeletes`)
2. Обратитесь к администратору базы данных для восстановления из резервной копии
3. Или создайте новую роль с тем же именем
