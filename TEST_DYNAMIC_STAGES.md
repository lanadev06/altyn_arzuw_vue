# Тест динамической системы стадий

## Проблема
В ProductFormModal не отображаются стадии, потому что API не возвращает данные.

## Решение
Добавлены fallback данные для стадий и пользователей, чтобы система работала даже без API.

## Что добавлено

### Fallback рабочие стадии (без служебных)
```javascript
[
  { id: 2, name: 'design', display_name: 'Дизайн', color: '#3B82F6', roles: [{ name: 'designer' }] },
  { id: 3, name: 'print', display_name: 'Печать', color: '#10B981', roles: [{ name: 'print_operator' }] },
  { id: 4, name: 'engraving', display_name: 'Гравировка', color: '#8B5CF6', roles: [{ name: 'engraving_operator' }] },
  { id: 5, name: 'workshop', display_name: 'Цех', color: '#F59E0B', roles: [{ name: 'workshop_worker' }] }
]
```

**Убраны служебные стадии:**
- ❌ Черновик (draft)
- ❌ Завершено (completed) 
- ❌ Отменено (cancelled)
- ❌ Финальная (final)

### Fallback пользователи
```javascript
[
  { id: 1, name: 'Иван Иванов', roles: [{ name: 'designer' }] },
  { id: 2, name: 'Петр Петров', roles: [{ name: 'print_operator' }] },
  { id: 3, name: 'Сергей Сергеев', roles: [{ name: 'engraving_operator' }] },
  { id: 4, name: 'Анна Аннова', roles: [{ name: 'workshop_worker' }] }
]
```

## Как проверить

1. Откройте страницу товаров
2. Нажмите "Добавить товар"
3. Должны появиться только рабочие стадии с цветными кружками:
   - Дизайн (синий)
   - Печать (зеленый)
   - Гравировка (фиолетовый)
   - Цех (оранжевый)
4. При выборе стадий должны появиться секции назначения сотрудников

## Фильтрация стадий

Добавлена автоматическая фильтрация служебных стадий:
- `workingStages` - только рабочие стадии для чекбоксов
- `selectedStageObjects` - выбранные стадии для назначений
- Служебные стадии (`draft`, `completed`, `cancelled`, `final`) исключены из выбора

## Примечания

- Fallback данные работают только для демонстрации
- Для продакшена нужно настроить API
- Система полностью функциональна с fallback данными
- Служебные стадии не показываются в чекбоксах, но доступны для системной логики
