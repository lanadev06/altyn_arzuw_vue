# Обновление системы назначений продуктов

## Изменения в системе

### Раньше:

- На каждый продукт можно было назначить только одного дизайнера, одного оператора печати и одного работника цеха
- Простая связь один-к-одному

### Теперь:

- На каждый продукт можно назначить несколько дизайнеров, несколько операторов печати и несколько работников цеха с приоритетами
- Связь многие-ко-многим с приоритетами

## Технические изменения

### 1. Обновлены типы (`src/types/product.ts`)

Добавлен новый интерфейс `ProductAssignment`:

```typescript
export interface ProductAssignment {
  id: number
  user_id: number
  priority: number
  user?: { id: number; name: string }
}
```

Обновлен интерфейс `Product`:

```typescript
export interface Product {
  // ... существующие поля ...
  // Новые поля для множественных назначений
  designers?: ProductAssignment[]
  print_operators?: ProductAssignment[]
  workshop_workers?: ProductAssignment[]
}
```

## API изменения

### Ожидаемые изменения в API:

1. **Создание продукта** (`POST /api/products`):

```json
{
  "name": "Название продукта",
  "has_design_stage": true,
  "has_print_stage": true,
  "has_engraving_stage": false,
  "has_workshop_stage": true,
  "designers": [
    { "user_id": 1, "priority": 1 },
    { "user_id": 2, "priority": 2 }
  ],
  "print_operators": [{ "user_id": 3, "priority": 1 }],
  "workshop_workers": [
    { "user_id": 4, "priority": 1 },
    { "user_id": 5, "priority": 2 }
  ]
}
```

2. **Обновление продукта** (`PUT /api/products/{id}`):

```json
{
  "name": "Обновленное название",
  "designers": [
    { "id": 1, "user_id": 1, "priority": 1 },
    { "user_id": 2, "priority": 2 }
  ]
}
```

3. **Получение продукта** (`GET /api/products/{id}`):

```json
{
  "id": 1,
  "name": "Название продукта",
  "designers": [
    {
      "id": 1,
      "user_id": 1,
      "priority": 1,
      "user": { "id": 1, "name": "Иван Иванов" }
    }
  ],
  "print_operators": [...],
  "workshop_workers": [...]
}
```

## Миграция данных

При необходимости миграции существующих данных:

1. Создать таблицу `product_assignments` с полями: `id`, `product_id`, `user_id`, `role`, `priority`
2. Перенести существующие назначения в новую структуру
3. Установить приоритет 1 для всех существующих назначений

## Использование

### В форме создания/редактирования продукта:

1. Включить соответствующий этап (дизайн, печать, цех)
2. Нажать "Добавить" для добавления назначения
3. Выбрать пользователя из списка (доступны только неназначенные)
4. Приоритет устанавливается автоматически
5. При необходимости добавить дополнительные назначения
6. Система автоматически предотвращает дублирование

### В списке продуктов:

- Назначения отображаются с цветовой индикацией приоритетов
- Сортировка по приоритету (1, 2, 3...)
- Если назначений нет, отображается "Не назначены"
