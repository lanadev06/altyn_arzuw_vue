# Руководство по динамической системе стадий

## Обзор

Теперь у вас есть полностью динамическая система управления стадиями производства, которая позволяет:

1. **Создавать и управлять стадиями** через админку
2. **Назначать роли на стадии** (дизайнеры, печатники, гравировщики, работники цеха)
3. **Выбирать стадии для товаров** при их создании
4. **Выбирать стадии для заказов** при их создании
5. **Назначать сотрудников на конкретные стадии** в заказах

## Как использовать

### 1. Управление стадиями (Админка)

Перейдите в раздел **Админка → Управление стадиями**:

- **Создание стадии**: Нажмите "Добавить стадию"
  - Укажите название (например: "Дизайн", "Печать", "Гравировка")
  - Выберите цвет для визуального отличия
  - Установите порядок стадии
  - Отметьте, является ли стадия начальной или финальной

### 2. Назначение ролей на стадии (Админка)

Перейдите в раздел **Админка → Управление связями стадий и ролей**:

- **Добавление роли к стадии**: Нажмите "Добавить роль" для нужной стадии
  - Выберите роль (дизайнер, печатник, гравировщик, работник цеха)
  - Настройте параметры:
    - **Обязательная роль**: Роль должна быть заполнена обязательно
    - **Автоназначение**: Роль будет автоматически назначаться

### 3. Создание товара с динамическими стадиями

При создании товара:

1. **Выберите стадии**: Отметьте чекбоксы для стадий, которые нужны для этого товара
2. **Назначьте сотрудников**: Для каждой стадии назначьте сотрудников на соответствующие роли
3. **Сохраните**: Товар будет создан с выбранными стадиями и назначениями

### 4. Создание заказа с динамическими стадиями

При создании заказа:

1. **Выберите продукт**: Система автоматически покажет доступные стадии продукта
2. **Выберите стадии заказа**: Отметьте чекбоксы для стадий, которые нужны в этом заказе
3. **Назначьте исполнителей**: Для каждой стадии назначьте конкретных сотрудников
4. **Сохраните**: Заказ будет создан с выбранными стадиями и назначениями

## Преимущества новой системы

### ✅ Гибкость
- Можете создавать любые стадии (не только дизайн, печать, гравировка, цех)
- Можете настраивать роли для каждой стадии индивидуально
- Можете выбирать разные стадии для разных товаров

### ✅ Точность назначений
- Назначаете сотрудников именно на те стадии, где они нужны
- Можете назначать разных сотрудников на разные стадии одного заказа
- Система отслеживает назначения по стадиям

### ✅ Управляемость
- Все настройки в админке
- Можете изменять стадии и роли без перепрограммирования
- Система автоматически обновляет интерфейс

## Примеры использования

### Пример 1: Простой товар
- **Товар**: Визитки
- **Стадии**: Дизайн → Печать
- **Назначения**: 
  - Дизайн: Иван (дизайнер)
  - Печать: Петр (печатник)

### Пример 2: Сложный товар
- **Товар**: Подарочные коробки
- **Стадии**: Дизайн → Печать → Гравировка → Сборка
- **Назначения**:
  - Дизайн: Мария (дизайнер)
  - Печать: Алексей (печатник)
  - Гравировка: Сергей (гравировщик)
  - Сборка: Анна (работник цеха)

### Пример 3: Кастомный заказ
- **Заказ**: 100 футболок с логотипом
- **Выбранные стадии**: Дизайн → Печать (гравировка не нужна)
- **Назначения**:
  - Дизайн: Ольга (дизайнер)
  - Печать: Дмитрий (печатник)

## Миграция со старой системы

Старая система с чекбоксами (`has_design_stage`, `has_print_stage` и т.д.) продолжает работать для обратной совместимости. Новые товары и заказы будут использовать динамическую систему.

## Техническая информация

### Структура данных
- **Стадии**: `stages` таблица с полями `name`, `display_name`, `color`, `order`
- **Роли стадий**: `stage_role` таблица связывает стадии с ролями
- **Назначения**: `product_assignments` и `order_assignments` с полем `stage_id`

### API endpoints
- `GET /api/stages` - получить все стадии
- `GET /api/stages/{id}/roles` - получить роли стадии
- `POST /api/products/{id}/assignments` - назначить сотрудников на товар
- `POST /api/orders/{id}/assignments` - назначить сотрудников на заказ
