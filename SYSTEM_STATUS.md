### **Новая структура данных:**

```typescript
// Продукты
interface Product {
  id: number
  name: string
  available_stages: ProductStage[] // ✅ НОВОЕ
  // has_design_stage: boolean      // ❌ УСТАРЕВШЕЕ (но работает)
}

// Заказы
interface Order {
  id: number
  current_stage: string // ✅ НОВОЕ
  current_stage_info: StageInfo // ✅ НОВОЕ
  assignments: Assignment[] // ✅ НОВОЕ
  // stage: string                  // ❌ УСТАРЕВШЕЕ (но работает)
}

// Назначения
interface Assignment {
  id: number
  user_id: number
  role_type: string
  assigned_stages: Stage[] // ✅ НОВОЕ
}
```

### **API Endpoints:**

```typescript
// ✅ НОВЫЕ ENDPOINTS
GET    /api/stages                    - Все стадии
POST   /api/stages                    - Создать стадию
PUT    /api/stages/{id}               - Обновить стадию
DELETE /api/stages/{id}               - Удалить стадию

GET    /api/roles                     - Все роли
POST   /api/roles                     - Создать роль

GET    /api/products/{id}/stages      - Стадии продукта
PUT    /api/products/{id}/stages      - Обновить стадии

POST   /api/orders/{id}/bulk-assign   - Массовые назначения
```
