# Отладка проблемы с удалением стадий на фронтенде

## Проблема

Стадии не удаляются на фронтенде, хотя API работает корректно.

## Анализ проблемы

### 1. Проверка прав доступа

- **Backend**: Требует роль 'admin' для удаления стадий (StagePolicy)
- **Frontend**: Добавлена проверка `canDelete()` функции

### 2. Проверка аутентификации

- **Backend**: Требует токен авторизации
- **Frontend**: Добавлена проверка наличия токена в localStorage

### 3. Возможные причины проблемы

#### A. Пользователь не аутентифицирован

- Нет токена в localStorage
- Токен истек
- Пользователь не залогинен

#### B. Пользователь не имеет прав

- У пользователя нет роли 'admin'
- Роли не загружены корректно

#### C. Ошибки в API запросе

- Неправильный URL
- Неправильные заголовки
- CORS ошибки

#### D. Ошибки в обработке ответа

- Неправильная обработка ошибок
- Отсутствие уведомлений пользователю

## Внесенные исправления

### 1. Добавлено логирование

```typescript
// В StageList.vue
const handleDeleteStage = async (stageId: number) => {
  try {
    console.log('🔄 Начинаем удаление стадии:', stageId)

    // Проверяем права доступа
    if (!canDelete()) {
      alert('У вас нет прав для удаления стадий')
      return
    }
    console.log('✅ Права доступа проверены')

    // Проверяем токен авторизации
    const token = localStorage.getItem('auth_token')
    if (!token) {
      alert('Необходима авторизация для удаления стадии')
      return
    }
    console.log('✅ Токен авторизации найден')

    await StageController.delete(stageId)
    console.log('✅ Стадия успешно удалена:', stageId)
    // ...
  } catch (err: unknown) {
    console.error('❌ Ошибка удаления стадии:', stageId, err)
    if (err instanceof Error) {
      alert(`Ошибка удаления стадии: ${err.message}`)
    } else {
      alert('Произошла неизвестная ошибка при удалении стадии')
    }
  }
}
```

## Инструкции по отладке

### 1. Проверка аутентификации

1. Откройте DevTools (F12)
2. Перейдите на вкладку Application/Storage
3. Проверьте localStorage:
   - `auth_token` - должен содержать токен
   - `user` - должен содержать данные пользователя с ролями

### 2. Проверка прав доступа

1. В консоли выполните:

```javascript
// Проверить токен
console.log('Token:', localStorage.getItem('auth_token'))

// Проверить пользователя
console.log('User:', JSON.parse(localStorage.getItem('user') || '{}'))

// Проверить роли
const user = JSON.parse(localStorage.getItem('user') || '{}')
console.log('Roles:', user.roles)
```

### 3. Тестирование API

1. Откройте файл `test-stage-deletion.html` в браузере
2. Проверьте токен и права доступа
3. Попробуйте удалить стадию через тестовый интерфейс

### 4. Проверка сетевых запросов

1. Откройте DevTools → Network
2. Попробуйте удалить стадию
3. Проверьте запрос DELETE к `/api/stages/{id}`
4. Проверьте заголовки и ответ

## Возможные решения

### Если пользователь не аутентифицирован:

1. Войдите в систему заново
2. Проверьте, что токен сохраняется при входе
3. Проверьте, что токен не истекает слишком быстро

### Если пользователь не имеет прав:

1. Убедитесь, что у пользователя есть роль 'admin'
2. Проверьте, что роли загружаются корректно
3. Обновите данные пользователя

### Если есть ошибки API:

1. Проверьте, что Laravel сервер запущен на порту 8000
2. Проверьте CORS настройки
3. Проверьте логи Laravel для ошибок

### Если есть ошибки фронтенда:

1. Проверьте консоль браузера на ошибки JavaScript
2. Проверьте, что все импорты работают корректно
3. Проверьте, что компоненты загружаются
