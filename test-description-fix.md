# Тестирование исправления проблемы с описанием

## Проблема

Описание не удалялось в стадиях и ролях при попытке очистить поле.

## Исправления

### 1. StageFormModal.vue

- Изменено: `description: form.description || undefined`
- На: `description: form.description.trim() || null`

### 2. RoleFormModal.vue

- Изменено: `description: form.description || undefined`
- На: `description: form.description.trim() || null`

### 3. StageManager.vue

- Добавлена обработка: `description: form.value.description.trim() || null`

### 4. RoleManager.vue

- Добавлена обработка: `description: form.value.description.trim() || null`

## Как протестировать

1. Откройте приложение
2. Перейдите в раздел "Стадии" или "Роли"
3. Создайте новую стадию/роль с описанием
4. Сохраните
5. Отредактируйте стадию/роль
6. Очистите поле описания (удалите весь текст)
7. Сохраните
8. Проверьте, что описание действительно удалилось

## Ожидаемый результат

- При очистке поля описания и сохранении, описание должно быть установлено в null в базе данных
- При повторном открытии формы редактирования, поле описания должно быть пустым
- В списке стадий/ролей должно отображаться "Нет описания" или пустое место

## Техническое объяснение

**Проблема была в том, что:**

- `form.description || undefined` возвращало `undefined` только для falsy значений
- Пустая строка `""` не является falsy в контексте `||`
- Бэкенд ожидал `null` для удаления описания

**Решение:**

- `form.description.trim() || null` сначала удаляет пробелы, затем возвращает `null` для пустых строк
- `null` корректно обрабатывается бэкендом как "удалить описание"
- `trim()` также решает проблему с пробелами
