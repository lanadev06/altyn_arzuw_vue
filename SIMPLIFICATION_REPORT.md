- ✅ Оставил только базовую информацию о ролях и пользователях

**Было:**
```php
'role' => [
    'id' => $role->id,
    'name' => $role->name,
    'display_name' => $role->display_name,

        'auto_assign' => $role->pivot->auto_assign ?? true
    ]
]
```


## 📋 **Текущая функциональность**

### **Создание стадии:**
1. Вводим название и описание
2. Выбираем роли для стадии (простой чекбокс)
3. Сохраняем

### **Создание роли:**
1. Вводим название и описание
2. Выбираем стадии для роли (простой чекбокс)
3. Сохраняем

### **Создание продукта:**
1. Вводим название продукта
2. Выбираем стадии
3. Вручную назначаем пользователей из списка доступных
4. Сохраняем
