### 📋 **ШАГ 2: Тестирование фронтенда (8 мин)**

#### **2.1. Создание продукта (2 мин)**

1. Откройте `/products`
2. Нажмите "Добавить товар"
3. Заполните название
4. Выберите стадии (должны загрузиться из API)
5. Сохраните

**✅ Ожидаемый результат:**

- Стадии загружаются динамически
- Можно выбрать несколько стадий
- Можно установить стадию по умолчанию

#### **2.2. Создание заказа (3 мин)**

1. Откройте `/orders`
2. Нажмите "Добавить заказ"
3. Выберите продукт
4. Заполните остальные поля
5. Сохраните

**✅ Ожидаемый результат:**

- Заказ создается с `current_stage: "draft"`
- Нет ошибок 422 о missing current_stage

#### **2.3. Проверка отображения (3 мин)**

1. Проверьте список продуктов - должна быть колонка "Стадии"
2. Проверьте список заказов - стадии должны отображаться с цветами
3. Проверьте детали заказа - должны показываться назначения

**✅ Ожидаемый результат:**

- Цветные стадии в списках
- Корректное отображение назначений
- Нет ошибок в консоли

### 📋 **ШАГ 3: Проверка совместимости (4 мин)**

#### **3.1. Старые данные (2 мин)**

1. Создайте продукт со старыми полями (через API)
2. Проверьте, что он отображается корректно
3. Отредактируйте его - должна работать новая система

#### **3.2. Новые данные (2 мин)**

1. Создайте продукт с новой системой
2. Проверьте, что все работает корректно
3. Убедитесь, что старые поля не используются
